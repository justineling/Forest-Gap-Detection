## Forest Gap Detection — 可行性分析与架构方案（项目启动）

**背景**：用户启动新项目，Windows 桌面端 Tauri 应用，输入无人机正射影像 tif（~3GB）+ KML 边界，AI 检测油棕园空地并生成 polygon，输出 JSON。用户要求先出 HTML 架构方案文档，确认后才允许开发。项目零代码起步（仓库仅有 README.md）。

**执行方式**：以「软件开发团队」专家团的**部分工作流**执行 —— 产品经理（PRD）→ 架构师（系统设计）→ 主理人汇编 HTML。另开一路专项研究攻克 AI 模型与数据来源问题。

**产出文件**（均在 `docs/`）：
- `PRD.md` — 简单 PRD，含 P0/P1/P2 需求池、用户故事、UI 草稿、14 项待确认问题
- `system_design.md` — 完整系统架构设计（选型对比、文件列表、类图、时序图、5 任务分解、共享约定）
- `class-diagram.mermaid` / `sequence-diagram.mermaid` — 图表源文件
- `model-strategy.md` — AI 模型与数据路线研究（10 项开源方案盘点、25 条来源链接、精度验收基线）
- `architecture-proposal.html` — **最终交付物**，自包含 HTML 架构方案（11 节）

**已确立的关键决策**（后续开发须遵循）：
1. 推理执行：**Python sidecar 为主 + 纯 Rust `ort` 为可选降级**，通过 `InferenceEngine` trait 解耦；模型以 ONNX 分发，PyTorch 仅用于训练/导出（避免安装包膨胀到 GB 级）
2. 影像渲染：**后端 GDAL 生成本地 XYZ 瓦片 + 前端 MapLibre GL(WebGL)**；Canvas 直接绘制在 3GB 下不可行
3. 模型路线：**开源预训练迁移/微调优先**（DeepForest MIT + SAM2 Apache 2.0），自研训练暂不考虑；推荐「零标注冷启动出 v1 → 少量标注微调迭代」
4. 架构做 **α/β 双路线兜底**，差异仅收敛在 3 处（InferenceEngine 实现 / ModelRegistry 后端 / ModelConfig 的 device-provider），其余模块不变 → 关键未知未澄清前架构即可冻结

**重要技术发现**：
- 空地检测核心链：树冠 mask → **取补集** → Polygonize → 简化 → 面积过滤 → 打标
- **单期 RGB 无法区分「长期闲置」与「枯死」**（时间维度问题），需多期影像或多光谱/DSM；v1 降级为几何分类 + 人工复核，数据模型用 `class_confidence` / `class_method` 字段预留升级空间
- 分块推理接缝用 128px overlap + 羽化融合解决（独立步骤，非细节）
- 油棕树冠分割已有公开实证：ForestSAM Dice 0.826 / IoU 0.712

**状态**：等待用户确认架构方向并回答 Q01–Q06（多期影像 / 波段 / 是否已有模型 / 标注数据 / GPU / 空地阈值）。确认后启动完整开发 SOP（工程师 T01→T05，QA 验证）。

## 追加：需求变更 v0.2（同日，用户澄清后收敛）

**用户澄清的三点**：
1. 质疑 TIF 为何叫"影像"（实为 GeoTIFF 科普问题）→ 已解释：GeoTIFF = 图片 + 地理坐标，像素知道自己在地球上的位置与地面尺寸，所以能算面积、输出经纬度多边形。
2. **检测目标只需 1 个类「空地」**，不需要区分长期闲置/枯死，不涉及时间维度，只关心"哪些土地还空着"。
3. 质疑为何分三类、KML 是否刚需 → 已解释：KML 与 TIF 不是二选一（KML=范围，TIF=数据），设计上 KML 改为可选。

**需求收敛结果（做减法）**：
- 三类 `idle`/`hole`/`gap` **全部取消** → 单类「空地」，本质二值判定（树冠 vs 非树冠）
- **KML 从 P0 降为 P1**：无 KML 时用 `KmlProcessor.single_block_from_raster(meta)` 构造覆盖全图的单 block
- 「林间空隙 vs 枯死缺株」二分类**降为 P2 可选增强**，`class` 字段保留备用
- 任务结构不变（仍 T01–T05），但 T02–T05 工作量均减少

**关键技术结论（回答"能否区分林间空隙与枯死缺株"）**：
- 正常 vs 空地：**高可信**，可承诺
- 枯死 vs 未种（病理）：**不可辨识** —— 单张照片不含"树曾活着"的历史信息，这是物理观测极限
- 林间空隙 vs 枯死缺株：**中等可信** —— 通过**把"枯死缺株"重新定义为「株位空缺」（几何问题）**，用**株行距网格先验**判定：落在网格节点上的空缺 = 株位空缺；不在网格上、形态不规则的 = 林间空隙。这样绕开了无法解决的病理判断
- 失效条件：种植不规则 / 缺株率 >30~40% / 行随地形弯曲 / 树冠严重粘连 → 应降级为单类并提示人工复核
