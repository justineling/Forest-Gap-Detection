## 下午：自动跳步 + 卡片折叠 + 数据目录搬 D 盘（`3207e94`）

### 问题 1：换影像选同一张 tif 仍跳第 4 步（三层叠加）
1. 后端 `should_clear_gaps` 要求 `new_image != old_image` → 同一张不清 `cfg.gaps`
2. 前端 `onWizardDone` 用 `shouldClearGapsOnImageChange`（同一张 → false）→ 不清界面
3. `probeAndLoad` 紧接着 `loadGaps()`，`/gaps` 扫 `output/` → 旧结果又回来

修：后端 `!gaps_given`（向导提交 = 重新开始）+ 前端无条件 `setGaps([])` +
`skipNextLoad` 闸门跳过紧随其后那次加载。`shouldClearGapsOnImageChange` 保留但标注弃用。

### 问题 1.1：跳步后卡片折叠
`NextStepCard` 的 `collapsed` 是内部 state，折叠过一次就一直折叠 →
`useEffect(() => setCollapsed(false), [action.step, action.finished])`。

### 问题 2：数据目录搬 D 盘
- `bundled_data_root` 新增便携分支：程序旁 `data/`（`dir_is_writable` 实测可写），
  优先级在 `%LOCALAPPDATA%` 之前；Program Files 只读时自动回退。
- `migrate_from_localappdata`：搬 `settings.json` + `output/`（≤200 MB，`copy_dir_capped`）。
- 「打开输出目录」改用 `appStatus.data_root`，不再用 localStorage 的 `outputDir`。

### 用户问的 ArcGIS 差异（已实测确认）
`output/wgr17-desktop-gaps.geojson`（26 MB）**不是标准 GeoJSON**：
- 顶层**没有 `features`**，结果嵌在 `blocks[0].gaps`（1726 个 Feature）
- `crs` 是字符串 `"EPSG:4326"`，不是标准对象
→ ArcGIS 按规范找 `features` 找不到，导入失败。

`desktop-export/gaps-all-wgs84.geojson`（11 MB）是标准 FeatureCollection：
- `features: 1726`、`crs: {type: name, properties: {name: EPSG:4326}}`
- 坐标 `[111.204, 1.190]`（经纬度）
→ ArcGIS 正常。

**结论**：`output/` 是内部中间产物（界面按"作业块"管理，所以嵌套），
`desktop-export/` 才是交付格式。**给 ArcGIS 的一律用导出的**。

### error #310（我的低级错误）
`#310` = "Rendered more hooks than during the previous render"。
我昨天加的 `if (input.detectRunning) return null` 插在了**家机原有的
`useEffect`（步骤变化自动展开）之前** → 检测开始时 hook 从 3 个变 2 个 → 白屏。

修：把 `abnormal` + `useEffect` 提到 `return null` 之前，并删掉我加的**重复**
effect（家机原本就有一个 `[action.step, action.kind, abnormal]`）。

`npm test` 是纯单元测试（不渲染组件）→ 抓不到；项目 eslint 是旧 `.eslintrc`
格式、新版 eslint 跑不了 → 也没有 lint 兜底。**以后改组件先 grep hook 顺序**。

### settings.json 不在 data/ 下
根因：`config_path()` 一直是 `%LOCALAPPDATA%\fgd\settings.json`
（**data/ 的上一级**），而我的迁移函数去 `data/settings.json` 找 → 找不到。
修：`config_target()` 便携优先（`data/settings.json`）+ `load_config` 读老位置并
顺手迁移 + `migrate_from_localappdata` 从 `legacy_config_path()` 取。
