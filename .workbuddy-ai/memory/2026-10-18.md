## 二、动手前发现的两个真 bug（比进度条严重）

### 1. `forest_mask_path` 从来没传过

`TopToolbar.tsx` 拼参数时只有 `input` / `job` / `chm_path` / `segment_path` /
`workers` / `target_density_per_ha`，**没有 forest_mask_path**。
→ 桌面端检测结果一直包含未开发林，正是 `wgr17-elev-gaps` vs `wgr17-final-gaps`
的差（**多 221 个放样点**）。CLI 版本靠 `--forest-mask` 传，桌面端漏了。

### 2. `warn` 事件没有处理分支

App.tsx 的事件处理只有 `progress` / `result` / `error` / `log`，
`warn`（W1001 未知字段 / W1004 CHM 缺失 / W3001 水体）**全部被丢弃**。
这解释了为什么之前"静默退化"连提示都看不到 —— 双重静默。

## 三、实现

### 后端：`preflight_detect`（Rust）

7 类检查，error 阻塞 / warn 需确认 / info 只提示：

| 项 | 缺失后果 | 级别 |
|---|---|---|
| 正射影像 | 无法检测 | error |
| CHM | 退化纯 RGB | warn |
| 语义分割 | 水塘识别 98% → 8% | warn |
| 森林掩膜 | 未开发林算成可补种 | warn |
| 输出目录 | 白跑 350 秒 | error |
| 圈选 | 只影响范围 | info |
| workers/密度 | sidecar E1002 | error |

关键设计：
- **森林掩膜自动发现**：`output/forest-mask*.geojson` 前缀取最新，写回 `resolved`
  （文件名是实验名，写死会在换影像后失效）
- **输出目录探针**：`create_dir_all` 后真写 `.fgd-write-probe` 再删
  （建得出来 ≠ 写不进去）
- **可测**：抽成 `preflight_core(base, params)` 纯函数，10 个单测在 temp 下自建目录，
  不依赖 `output/`（gitignore 的，换机器就没有）

### 前端

- `DetectBar`：工具栏下方进度带。`检测中 24% · 128/528 块 · 已用 1:25 · 剩余 4:24 ·
  已发现 312 块`；跑完变结果摘要。**不做模态** —— 350 秒里还要看图翻图层。
- `PreflightDialog`：预检卡片，error 只能「去选择数据」，warn 可「仍然开始」。
- `DetectSettings`：齿轮弹层，只给 3 个开关（workers / 密度 / 只跑圈内），
  存 localStorage。
- 预检**全绿直接开跑**，不打扰。

## 四、踩到的坑

1. **`done=0` 不能用 `||`**：`done: p.done || s.done` 会让第一块完成前进度条永远不动。
   必须 `??`。
2. **`.app` 用 `grid-template-rows: auto 1fr auto` + 可选孩子 → 错位**：
   加进度条后孩子数在 3/4 之间变，`1fr` 被分给状态栏，body 变成 `auto`
   （地图区压成内容高度）。改成 `flex column` + `body { flex: 1 }`。
3. **参数弹层不能写死 `top: 52px`**：工具栏 brand 是两行、窄窗口还会换行。
   包进 `.tb-wrap { position: relative }` + `top: calc(100% + 6px)`。
4. **`?detect=1` / `?pf=1` 预览参数**：浏览器模式没法触发检测，加这两个
   query 才能截图验证新 UI（`wizard=1` 已有先例）。这很关键 ——
   「组件写了」不等于「渲染得出来」，上次 43 项断言全绿时页面是白的。

### 8.1 撤销/重做

- 快照式，40 步。**快照便宜的原因**：要素对象从不可变 → `gaps.slice()` 只是
  1,726 个指针（约 14 KB）。绝不能改深拷贝。
- 批量操作只压 1 步（`batchDeleteGaps` / `batchSetClass`）。
- 新操作清空 `future`，否则时间线分叉。
- **★ 拖拽 change 洪水**：TerraDraw 拖顶点时每几个像素触发一次 change，
  一次拖拽几十次 `updateGapGeometry`。加了 1.5 s 时间窗合并（12 次 → 1 步），
  `setGaps` 重置窗口。

### 8.2 框选

`selectGapsInBox(features, bbox, visibleClasses, mode)` 纯函数。
**必须传 visibleClasses** —— 默认只勾选「确定需补种」，隐藏的 road/water

不用 `queryRenderedFeatures`（随缩放变、测不到、不分类别）。

交互：进模式 disable `dragPan`/`boxZoom`（MapLibre 把 Shift+拖拽绑成拉框放大）；
`mouseup` 挂 window 以便拖出画布也能收尾。

### 8.3 复核清单

### 9.1 KML / GeoJSON 范围导入

`lib/roiImport.ts` 纯函数，**不用 DOMParser**（只在浏览器存在，测不到）。

- **★ 剥第 3 维**：KML 是 `lon,lat,alt`，第 3 维混进 geometry 会让面积与
  Terra Draw 静默算错。单测断言 `ring.every(p => p.length === 2)`。
- **多多边形取最大**：KML 常含"目标区块 + 图例框"，合并会虚增范围。
- 导入后 `setRoi` → MapCanvas 5b effect 自动 fitBounds。
- 28 项断言（三维 / 取最大 / 换行 / 未闭合 / MultiPolygon / 四类错误）。

### 9.2 权威导出

`/export` 原来只写 geojson/csv/kml → 人工复核结果落不进 Shapefile。
现在复用 `export_arcgis.build_features()`（新抽出的内存版入口）+
`write_shp_zip` / `write_kml` / `export_planting_points`。

**⚠️ 网格必须来自磁盘结果**：前端 `planting_grid` 只有 anchor_lon/lat，
缺 `origin_x_m/origin_y_m`，拿去构造 GridModel 会让点位整体平移。

实测 HTTP：1,726 要素 → **21 个文件 / 3,691 个放样点**。

### 9.4 输出目录
