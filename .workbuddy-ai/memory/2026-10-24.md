## 第八批：步间"灰方块" → 刻度线（tick）

用户："为什么 02/03/04/05 的左边会有个正方形？而且没有任何反馈。"

### 根因（值得记）
styles.css 的 `.sr-line { width: 18px; height: 1px; flex: 0 0 18px }`。
设计层只写了 `width: 1px; height: 14px` —— **`flex-basis` 优先于 `width`**，
所以宽度仍是 18px、高度被改成 14px → 渲染成 **18×14 的灰方块**，没有任何语义。
→ 教训：flex 子项的宽度必须连 `flex`/`flex-basis` 一起覆盖，只改 `width` 是静默无效。

### 修法（ark 的刻度轨语法）
