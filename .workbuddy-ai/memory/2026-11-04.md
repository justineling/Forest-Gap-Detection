## 2. 修跨瓦片重复计数（10-29 评审的 P0 缺陷 A / A′）

**根因**：瓦片外扩 128 px 读取，按质心判归属但几何原样保留 → 比外扩带宽的空地两块瓦片各输出一次。

**做法**：`_own_core`（只留 core 内，越过/贴着 core 边的打 `_seam`）→ `stitch_seams`（碎块全局 union，
空地四类不分类别合，合并后才过 min_area，在完整几何上重分类）→ `finalize_features`（CLI 与 sidecar 唯一入口）。

**三个坑**：
1. 裁剪必须在**源坐标系**（经纬度）里用 `clip_by_rect`：core 框在 UTM 下是斜的，缝两侧交点差几个 ulp，union 合不上。
2. "贴着 core 边"也要算碎块，不能只算"越过 core 边"（两块瓦片对缝两侧判断不一致时会留下贴着却没合的两块）。
3. 林地掩膜第一版用"面积占比 ≥50% 整块改判"，全幅一跑就露馅：缝合把跨掩膜边界的碎块连成大块，掩膜里那部分天然林
   整块算回需补种（改判面积随瓦片配置 5,804~16,637 m² 跳、树心落入数反升）。改为**沿掩膜切开**。
   **教训：任何"整块判一个类"的规则遇到跨边界大块都会错 —— 和 10-13 不可种植地物改按像素扣除是同一课。**

**顺带发现**：桌面端 `sidecar.py` **从来没调用林地掩膜**（预检界面写着「已自动启用」）。坑 70。
