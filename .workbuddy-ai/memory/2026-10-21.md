## 续 9：端口误报的真因（两个 bug）+ 体积优化

### 真因不是"端口被占"，是三个问题叠加
1. **服务崩溃（退出码 1）**，但日志只剩 `[tile_server] ====` 一行 ——
   `lib.rs` 的 stderr 读取用了 `.lines().map_while(Result::ok)`：
   **只要一行不是严格 UTF-8，迭代器整体停止**，后面的 traceback 全丢。
   横幅第二行是中文 → 大概率在这里断掉。
2. **前端误判顺序错**：`tileDiag.ts` 的 `explain()` 把"端口被占"放在
   "进程秒退"**前面**。服务崩溃后端口可能残留（TIME_WAIT），
   此时 `port_open=true / ours=false` → 误报"被别人占用"，
   把用户引向查端口 PID（南辕北辙）。
3. **端口回退其实从未触发**：`app.log` 里 `改用 8` 计数 = 0 ——
   因为 8765 每次都是空闲的（服务死得快，端口已释放），
   所以 `pick_backend_port` 正常返回 8765。回退逻辑本身没问题。

### 三处修复
- Rust：`read_until(b'\n')` + `String::from_utf8_lossy` 逐行读，坏字节变 � 但继续。
- 前端：`explain()` 改为**先判 exit_code 非 0**（最确凿），
  端口被占分支追加 `d.exit_code == null` 条件。
- ps1：PyInstaller 加 `--exclude-module torch/torchvision/cv2/av/transformers/matplotlib/pyogrio`
  （实测这 7 个在 `scripts/*.py` 里 **0 引用**；pandas 有 1 处引用，保留）。
  体积构成：torch 365 MB + cv2 111 MB + av 64 MB + pyogrio 48 MB + transformers 36 MB + matplotlib 14 MB
  ≈ 638 MB 全是死重。

### 验证
- **`cargo check` 通过（6m15s，零错误）** —— 这是端口回退代码第一次真正编译验证
