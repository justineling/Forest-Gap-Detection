右面板三档平级页签「清单｜验证集｜属性」（原「复核」+ 内层「复核｜验证集」）；
7 个弹窗统一一套外壳（零圆角 / 2px 顶线 / 无投影）；圆角全部归零；离线空舞台加蓝图网格。

## 关键坑（都写进代码注释了）

1. **`display:none` 会从 `innerText` 里消失** → 日志折叠用 `max-height` + `overflow:hidden`。
   用 `display:none` 藏旧行时，`verify_render` 12 处"日志里出现过某句话"的断言全假失败
   （实测场景 12「导出完成」直接红）。
2. **布局层写 `display` 会被设计层覆盖**：`@media(max-width:760px){.tb-brand{display:none}}`
   写在 styles.css 无效 —— ark.css 后 import 且同样单类名，`.tb-brand{display:flex}` 胜出。
   移到 ark.css 才生效。
3. **MapLibre 只监听 window resize**，不监听容器 → 命令条/侧栏变化必须补
   `ResizeObserver → map.resize()`，否则 canvas 被拉伸、影像与矢量多边形错位。
4. **每行独立 grid 的 `auto` 列宽逐行不同** → 复核行面积列必须定宽（88px），
   否则类别名在每行 x 位置都不一样。
5. **`repeat(5,1fr)` 配 4 个按钮** 会多出一条空列（看起来像"第五个按钮加载失败"）。
6. `.panel-head.tabs .tab-n` 特异性高于 `.tab-n`，圆角归零必须用同样选择器。

## 代码审核：用户自研的最近 5 个提交（d7caaeb / f2a3a6d / f50642e / c8bc617 / 7c17ee9）

**结论**：门禁全绿（tsc 0 / npm test 815 / verify_render 188），但发现 1 条会改错数据的中等问题 + 2 条中风险。

### 关键发现
1. **数字键 1–9 与左面板类别顺序不一致**（ReviewList.tsx:312 用 `ALL_CLASSES[n-1]`）。
   `ALL_CLASSES = Object.keys(CLASS_STYLES)` 是**声明序**（1..9），而面板按 `GROUP_ORDER`
   分组渲染，视觉顺序是 **1,2,9,4,3,5,6,7,8** —— 按 3 期望"人工新增"却改成"林间空隙"。
   注释（:304）写"顺序与左面板完全一致"是错的。改法：`GROUP_ORDER.flatMap(...)` 生成唯一序，
   键盘与面板共用，并在行首显示数字。
2. **瓦片 failed 判定会误报**（MapCanvas.tsx:134）：只排除 404，**被中止的请求（status 0/Abort）**
   计入失败；平移时 MapLibre 会中止在途瓦片 → 连续 3 次即判"影像读不出来"。且无时间窗，
   慢盘首屏会先闪红条再恢复。建议只在 `status>=400 && status!==404` 计数。
3. **降级文案断言了未证实的病因**（MapCanvas.tsx:613）："多半是被移动、改名、被占用"——
   `failed` 只能证明请求失败（网络/端口/500 都可能）。这与他们修的"界面在说谎"同类。
4. 次要：≤980px 时 `.sb-opt` 把"影像读不出来"整句隐藏（styles.css:3465）；
   `tileFails` 跨影像不清零；自动跳下一块在末行会跳进"已处理"区；multi 的 `area_sqm ?? 0` 让最小面积恒 0。

### 方法
除了读 diff，还用 headless CDP 打开 `?mock=ready&noResume=1`（无瓦片服务）**实际触发了 failed 分支**，
才看到 #3/#4 —— 静态读代码发现不了这两条。

## 修掉审核发现的 3 条真 bug + 2 条护栏（用户批准「如果真的是 bug」）

**先验证再动手** —— 用户明确要求"如果这些真的是bug"，所以每条都做了证据确认：

1. **键位错位（确认为真）**：用 headless 读真实 DOM，面板顺序实测
   `株位空缺/连片空地/人工新增/不确定/林间空隙/道路/水体/办公/非种植`，
   而 `ALL_CLASSES` 是声明序 `…/林间空隙/不确定/道路/…/人工新增` —— 按 3 会改成"林间空隙"。
   修法：新增 `CLASS_KEY_ORDER = GROUP_ORDER.flatMap(...)` 作唯一真值，键盘与面板共用；
   面板行首显示序号（`.cls-k`），用户不用记。
2. **tileFails 跨影像不清零（确认为真）**：计数器在 init effect 闭包里，effect 只在挂载跑一次
   → 换图后继承旧失败数，1 次失败就判 failed。修法：提到组件作用域 ref + `meta?.source` 变化时归零。
3. **abort 可能被计入失败（无法证实，加护栏）**：只排除 404；中止的请求没有 status。
   没法从 minified dist 确认 MapLibre 是否 fire error，所以加 `/abort/i.test(message)` 护栏 ——
   无害且能挡住"拖一下地图就报读不出来"。
4. **降级文案断言病因（确认为措辞问题）**：改成"可能被移动/改名/被占用，也可能服务端读盘出错"。
5. **≤980px 藏掉"影像读不出来"（实测确认为真）**：加 `.sb-state` 白名单，窄窗保留这一句。

**没改的一条**：`area_sqm ?? 0` —— `types.ts` 里 `area_sqm: number` 是必填，`?? 0` 只是防御，
不构成 bug。不动。
