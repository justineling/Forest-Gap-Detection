空地分割判据说明

为什么最终选「混合阈值」而不是纯分位或纯绝对 —— 附 WGR17.tif 实测证据
一句话结论
单张航拍 RGB 影像里，「什么算空地」不能靠一个固定数值判断。 最终采用 阈值 = clip(ExG 的 40% 分位, 下限 40, 上限 80) 再叠加「高饱和度视为植被」的辅助判据 —— 实测跨航带曝光差异 3 倍时， 冠层率仍稳定在 71%~88%。

1. 问题：什么叫「空地」？

油棕园的「空地」在业务上指 没有油棕树冠覆盖的地面，需要补种。 程序拿到的是普通航拍 RGB 影像，没有近红外、没有高度模型， 所以只能靠颜色判断「这块地是不是绿的」。

用的指标是 超绿指数 ExG： 

ExG = 2 × 绿 - 红 - 蓝

ExG 高 = 绿色植被；ExG 低 = 裸土、路面、水、阴影。 看起来很简单，但「多低算低」这一步出了大问题。

2. 前两版判据都翻车了

v1：纯分位阈值（40% 分位）—— 误报严重

做法：取全图 ExG 的 40% 分位当阈值，高于它的算树冠。 隐含假设是「影像里固定有 60% 面积是树冠」。

实测翻车：在密植区截取 23 m × 23 m 一块地，那里明明长满草和灌木 （肉眼可见是绿的），但因为林下植被比油棕羽叶暗，ExG 偏低， 被整片判成了「空地」。

根因：分位阈值是相对判据 —— 它回答的是 「这块地在全图里排第几」，而不是「这块地到底有没有绿」。 当一块区域整体偏暗时，它会被迫把一半的像素划成「空地」， 不管那些像素实际上是什么。

v2：纯绝对阈值（ExG > 60）—— 对曝光过敏

改成「ExG 必须大于 60 才算树冠」，判据直接、符合直觉。 在曝光正常的区域确实大幅消除了误报。

但进一步实测发现 WGR17.tif 各航带的曝光差异极大：

位置ExG 中位纯绝对 >60 判出的冠层率
密植区（亮）116.084%
东南79.571%
中南76.166%
中央53.444%
中左49.131%
中上48.738%

ExG 中位从 37 到 116，差了 3 倍。同一个 60 的阈值， 在亮航带上判出 84% 冠层，在暗航带上只剩 31%。 31% 意味着「七成地面是空的」—— 与影像上满屏油棕的事实完全矛盾。

根因：绝对阈值是绝对判据，但影像的辐射值不是绝对的。 不同航带、不同太阳高度角、不同飞行高度都会整体抬高或压低 ExG。 用一个固定数值去卡，必然在某个航带上失效。

3. 最终方案：混合阈值

阈值 = clip( ExG 的 40% 分位 , 下限 40 , 上限 80 )
树冠 = (平滑后 ExG > 阈值)  或  (饱和度 > 0.45)

为什么这样组合

  • 用分位自适应局部曝光：分位本身会跟着该区域的亮度走， 亮的地方阈值自动抬高，暗的地方自动压低。
  • 用 [40, 80] 夹逼，防止走极端： 分位算出来的阈值如果低于 40，说明这块地整体太暗 （多半是阴影或航带拼接差），此时强制用 40 兜底； 如果高于 80，说明这块地过曝，强制收敛到 80。 这正是 v1 和 v2 各自失效的两种极端情况。
  • 高饱和度兜底判为植被：真实裸土是红褐色、发灰的， 饱和度低；而林下杂草虽然 ExG 偏低，饱和度却仍然很高（鲜绿）。 所以「饱和度 > 0.45」的像素无论 ExG 多少都算树冠， 这能精准打掉「把杂草当空地」这类误报。

4. 怎么调这三个数字

参数默认调大的后果调小的后果
--pct40 判出的树冠更多 → 空地更少 树冠更少 → 空地更多（更容易误报）
--exg-lo40 暗航带被当空地的情况缓解 暗航带整片被判成空地
--exg-hi80 亮区域更容易判出空地 亮区域漏检空地
换影像时的标定步骤
  1. 跑 --grid-only 或直接看日志里的「冠层覆盖率」
  2. 若全局冠层率落在 60~80%，判据基本可用
  3. 若明显偏低（< 50%），说明影像整体偏暗 → 调低 --exg-lo
  4. 若明显偏高（> 90%）且人工核对确有遗漏空地 → 调高 --exg-hi
  5. 用 .workbuddy-ai/tmp/make_hybrid_compare.py 生成跨区域对比图人工复核

5. 工具与复现

# 默认即混合判据
python scripts/process_image.py --input D:/WGR/WGR17.tif

# 显式指定混合判据的三个数字
python scripts/process_image.py --input D:/WGR/WGR17.tif \
    --pct 40 --exg-lo 40 --exg-hi 80

# 关闭饱和度辅助（用于对比实验）
python scripts/process_image.py --input D:/WGR/WGR17.tif --no-saturation

# 回退到纯绝对阈值（不推荐，仅用于对比）
python scripts/process_image.py --input D:/WGR/WGR17.tif --exg-threshold 60

# 生成跨区域判据对比图
python .workbuddy-ai/tmp/make_hybrid_compare.py
参数指纹机制：以上任一参数变化都会改变任务的「参数指纹」， 已缓存的瓦片会自动失效重算，不会出现「改了参数却拿到旧结果」的情况。 详见 scripts/process_image.py 顶部的说明。

6. 诚实的局限

  • 「正常 vs 空地」高可信：几何意义上的「有没有树冠覆盖」 可以承诺，跨曝光也稳定。
  • 「是否枯死」无法判断：单张影像不含「这棵树曾经活着」的历史信息， 这是物理观测的极限。若业务需要，必须有多期影像或近红外/多光谱。
  • 稀疏园区的边界模糊：当植株间距本身就很大时， 「行间土壤」到底算不算需要补种，是种植管理决策，不是技术判断。 这种情况下建议人工复核 uncertain 类别。
  • 换影像必须重新标定：--exg-lo / --exg-hi 是基于 WGR17.tif 标定的。换一台相机 / 换一个季节， 请按第 4 节的步骤重新确认冠层率。
