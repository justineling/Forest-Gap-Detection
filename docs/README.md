# 项目资料索引

本目录存放 Forest Gap Detection（油棕园空地智能检测系统）的全部项目资料。
按主题分为 10 个子目录，**所有含图片的 HTML 都已把图片内联为 base64**，
因此无论放在哪个子目录、用双击还是预览面板打开，图片都能正常显示。

> **最后同步：2026-10-22** —— 算法已封版（Stage 14），桌面端（Tauri v2）已完成并出安装包。
> 权威算法说明见 `03-算法教学/算法说明与演进史.html`（含小白版）；
> **缺陷与改进清单（含修复记录）见 `03-算法教学/算法缺陷与改进清单.md`。**
>
> **桌面端现状（2026-10-21）** —— 五步工作流 + 复核三件套（撤销 / 框选 / 清单）+
> 21 件交付包与一页汇总报告；安装包 **68 MB**（内置完整 Python 运行时；早期未排除死重包时 286 MB）。
> 瓦片服务端口**不再写死 8765**（被占用自动换 8766~8776，前端跟随）；
> 打包链路已自动包含 PyInstaller 步骤。开发坑清单 **50 条**（`desktop/README.md`）。
> 使用手册见 `08-桌面端/桌面端使用手册.md`，实现说明见 `08-桌面端/桌面端实现说明.html`，
> 需要准备哪些文件见 `09-数据与产物/输入输出文件清单.html`。
>
> **验证集（2026-10-19）** —— 150 块真实标注跑完：合并口径样本准确率 **88.9%**、
> 全园加权 **77.9%**；大块（≥1,500 m²）40/40 全对，误差集中在小块（≤220 m²）。
