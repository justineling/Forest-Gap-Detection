# 项目资料索引

本目录存放 Forest Gap Detection（油棕园空地智能检测系统）的全部项目资料。
按主题分为 7 个子目录，**所有含图片的 HTML 都已把图片内联为 base64**，
因此无论放在哪个子目录、用双击还是预览面板打开，图片都能正常显示。

---

## 目录结构

```
docs/
├── 01-需求与架构/     需求、系统设计、可行性、架构方案、模型策略
├── 02-影像实测/       真实影像的规格报告与各区域探针图
├── 03-算法教学/       算法原理讲解（含配图）
├── 04-项目讲解/       项目全过程讲解 + 技术进展历程  ← 新人建议从这里开始
├── 05-环境与部署/     环境配置报告、Docker 方案对比
├── 06-科普与术语/     术语表、科普版项目简介
└── 07-检测成果/       整幅检测结果可视化
```

## 04-项目讲解（推荐入口）

| 文件 | 给谁看 | 内容 |
|---|---|---|
| `项目全过程-专业版.html` | 技术同事 / 接手开发的人 | 定位、输入输出契约、架构选型、处理链路、关键工程决策、算法方案、能力边界、当前状态 |
| `项目全过程-小白版.html` | 非技术人员 / 业务方 | 跟着一张照片走完 7 个处理站点，用大白话讲清整个系统在干什么 |
| `项目进展历程.html` | 所有人 | 技术路线的七次转折：DeepForest 折戟 → 结构法 → 空地分离 → 网格先验 → 整幅工程化 → 判据纠错 → 分类补全 |
| `小白版-01-这张照片到底是什么.html` | 零基础读者 | 正射影像、像素、地理坐标、为什么有 3.5 GB |
| `小白版-02-电脑怎么看出空地.html` | 零基础读者 | 颜色数值、绿度分数、分界线、连通的缝隙网、种植网格 |

**建议阅读顺序**：零基础 → 小白版 01 → 小白版 02 → 项目全过程-小白版 → 项目进展历程；
技术同事 → 项目全过程-专业版 → 项目进展历程 → 03-算法教学。

## 03-算法教学

| 文件 | 内容 |
|---|---|
