结论先说：数据不支持「几何自动排除」

原始假设是：这些大块空地是长条状的道路/排水沟预留带，可以靠长宽比自动识别剔除。

但实测形态数据否定了这个假设：这些区域的长宽比中位数只有 1.40， 全园 1048 块空地里长宽比 ≥3 的只有 2 块、共 465 m²（占 0.16%）。 它们根本不是条状，而是块状、近方形——而且大量是精确的 76 m × 76 m。

这意味着 A1（几何自动排除）在当前形态下无法工作。 需要改用位置/拓扑特征或A2（你提供矢量）。详见文末建议。

8. 对 A1 / A2 决策的建议

A1（几何自动排除）—— 当前形态下不可行

理由是硬数据：长宽比 ≥3 的只有 2 块 / 465 m²。 靠长宽比只能筛出 0.16% 的面积，而你要处理的是 82.6%。 这条路走不通——除非改判据。

A1'（改用面积 + 位置判据）—— 可行，但需要你确认

既然"形状"不行，可以用两个新特征：

  • 面积阈值：如 >600 m² 视为"非补种地块"——能覆盖 66% 的连片空地面积
  • 空间聚类：这些大块往往成片聚集，可以把相邻的大块合并成一个"预留区"多边形

优点：不需要额外素材。缺点：面积大 ≠ 不该种—— 也可能真的是一片需要补种的死树区。这一条必须你人工确认其中几块才能定。

A2（你提供矢量扣减）—— 唯一"语义正确"的方案

如果这些确实是园区规划的道路/排水/预留带，你手上应该有规划图 （CAD / SHP / KML 都行）。用它扣减是唯一不会误判的做法：

  • 算法只需新增一个"扣减图层"参数，gap = gap - reserved，改动很小
  • 结果可解释、可追溯，不会把"真该补种的大块死树区"误删
  • 一次投入，以后每期影像都能复用

代价：需要你提供素材。但如果拿不到矢量，也可以手工在图上圈一下—— 从分布图看，大块集中在少数几个区域，圈起来的工作量不大。

推荐路径

  1. 先做人工抽检：从上面第 7 节的清单里挑 5~10 块，在地图/影像上看看它们实际是什么 （道路？水塘？工棚？死树区？）—— 你一眼就能判断，我判断不了
  2. 如果确认多数是"规划用地"：走 A2，你提供矢量或用交互式地图圈选
  3. 如果发现它们其实该补种：那 open_patch 这个类别本身需要重新定义， 而不是简单地排除
  4. 如果拿不到矢量也不方便圈选：退而求其次用 A1'（面积 + 聚类）， 并在输出里把结果标为"候选预留区，需人工确认"

为什么不能跳过这一步： 这个口径决定了 82.6% 的空地面积怎么处理。 如果现在不定，等 Tauri 界面做完、补种图出图之后再改， UI 的结果面板、统计口径、导出格式全都要返工。
