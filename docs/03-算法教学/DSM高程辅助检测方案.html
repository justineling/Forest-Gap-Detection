DSM 高程辅助检测方案

Forest Gap Detection（油棕园空地智能检测）· 专业版  ·  2026-10-14  ·  对应代码版本 7440f0c
如果航测工程里能找到 DSM（数字表面模型），草地与油棕的区分问题 基本可以在一天内结案 —— 因为高度是物理量，不受航带曝光影响。

本文给出完整的 DSM 全流程设计：新增哪几步、每步的参数与注意事项、 怎么标定阈值、有什么风险、与旧流程的差异。

前提：需要拿到 DSM。本文假设能拿到；拿不到则走备用路线（见末节）。

一、为什么 DSM 能解决问题

问题回顾：草地与油棕在 RGB 上不可分。实测证据——

特征草地油棕结论
ExG 绿度83 ~ 951 ~ 112❌ 完全重叠
纹理 / 梯度 / 动态范围——❌ 重叠
8.45 m 排列周期性8.7~15.1%0~11.0%❌ 重叠
DINOv2 深度特征（实测）——❌ 5 个区域只对 1 个

根因：跨航带曝光差 3 倍（同一片油棕 ExG 从 1 到 112）， 把草地的 83~95 完整包住。所以不是"特征不够强"，而是 RGB 这个观测维度本身不够。

✅
高度是物理量。草 0.3~1.5 m，油棕（哪怕 1 年幼树）也 ≥ 2 m， 成熟油棕冠顶 7~15 m。曝光怎么变，高度都不会变。

这一点项目自己的《可行性分析.md》早就写明了：

DSM / CHM（冠层高度模型）—— 区分低矮杂草 vs 高大树冠 | 高 | 从摄影测量点云/激光雷达可得；大幅降低"杂草被误判为空地"

三、新流程逐步详解

0
数据准备与对齐检查

做什么：拿到 DSM 后，先确认它和正射影像同一坐标系、同一范围、像素对齐。

检查方法：

  • 两者 CRS 是否一致（预期 EPSG:4326 或同工程投影系）
  • 尺寸 / 分辨率是否一致 —— 摄影测量 DSM 的 GSD 常与正射不同， 若不同需重采样到正射的网格
  • 抽查几个明显地物（如道路交叉口）在两者中的像素位置是否吻合

为什么要查：DSM 与正射若错位几米，高度信息就会套到错误的地物上， 后面全部失效。同一工程导出的通常已对齐，但必须验证。

1
DTM 估算 —— 从 DSM 里"抠出"地面

问题：DSM 是地表表面（含树冠顶），不是地面。 树冠下面的地形看不见，而我们要算的是"地物高出地面多少"。

做法：滑动窗口低分位数滤波

  1. 在滑动窗口（建议 30~50 m，约 4~6 个株距）内取低分位数（5%~10%）
  2. 窗口内总会有空地/道路 → 低分位数近似该窗口的地面高程
  3. 对结果做中值滤波 + 平滑，得到连续的 DTM

关键参数：窗口大小。必须大于最大树冠直径（油棕冠幅 6~8 m）， 否则窗口里全是树冠，低分位数也会取到树冠高度。 建议 30 m 起步，用结果直方图验证（DTM 应明显低于 DSM 的众数）。

密林区的天然局限：如果某片区域完全被树冠覆盖（无空地/道路）， 窗口内取不到真正的地面点，DTM 只能靠邻域插值 → 该处高度会被低估。 但本园区有空地、道路、水塘作为地面控制点，整体可控。
2
CHM 计算 —— 得到"地物高度"

CHM = DSM − DTM

结果含义：每个像素上"东西高出地面多少米"。这是后续所有判断的基础。

必须做的后处理：

  • 中值滤波（3~5 px）—— 摄影测量 DSM 在树冠边缘有"毛刺"（立体匹配伪影）， 不清掉会造出假的"高矮边界"
  • 截断负值：CHM < 0 是噪声（DSM 略低于 DTM），置 0
  • 空洞填补：立体匹配失败处会是 NoData，需插值填补
3
高度分层 —— 一刀切开草地与油棕

初始阈值（待标定）：

高度区间判为后续处理
< 0.3 m裸地 / 硬化地面空地候选
0.3 ~ 1.5 m低矮植被（草 / 蕨） 空地候选 ← 这就是要补种的绿地
1.5 ~ 4 m幼树 / 灌木需人工判读
≥ 4 m成熟油棕树冠，排除
阈值必须标定，不能照搬。标定方法：取若干已知点 （你指认的草地真值点、明显的老油棕、明显的小树），读它们的 CHM 值， 据此定出 0.3 / 1.5 / 4 三条线。特别是 1.5 m 这条线—— 它决定"幼树算不算可种植"，需要你的领域判断。
4
树冠分割 —— 高度与绿度双证据融合

旧判据：树冠 = 平滑ExG > 阈值（单证据，会被草地骗）

新判据：

树冠 = (CHM ≥ 4 m) 或 (平滑ExG > 阈值 且 CHM ≥ 1.5 m)

逻辑：

  • 高度够高 → 一定是树（不管绿不绿、亮不亮）
  • 高度中等 + 绿度高 → 可能是树（幼树、受光冠层）
  • 高度低 → 不管多绿都不是树 ← 这一条直接解决草地问题

原来的 ExG 判据保留但降级：只在高度模糊的中间带起作用。

5-7
空地分离 → 矢量化 → 网格估计（沿用旧流程）

这三步逻辑不变，直接复用现有实现：

  • 空地分离：圆盘开运算断开窄缝（min_gap_width_m = 1.6， 距离变换实现，1.95 s/瓦片）
  • 矢量化：简化 + 面积门槛（simplify_m = 0.3，min_area = 30 m²）
  • 网格估计：株距 8.35 m / 行距 7.23 m / 错行角 60°（实测，质量 0.734）

唯一变化：分割的输入掩膜来自新的双证据判据。

8
空地分类 —— 新增「低矮植被」独立类别

在原有 4 类之外，用 CHM 再拆一类：

类别判据语义
株位空缺贴格点、形状规整、CHM 低补 1 株
林间空隙细长、远离格点无需补种
连片空地跨多株位、面积大整片补种
低矮植被 新 CHM 0.3~1.5 m 且成片 草地/蕨类，需补种（就是之前漏掉的那类）
不确定证据不足人工复核

好处：你可以直接在 ArcGIS 里把"低矮植被"单独成层， 一眼看到"哪些草地需要补种"——这正是原来做不到的。

9
不可种植地物检测（沿用 + 增强）

道路 / 水体 / 办公区三类沿用现有实现（landcover.py）。

DSM 带来的增强：

  • 水体：水面在 DSM 上是一个"平面"，且 CHM ≈ 0（甚至为负）。 原来的蓝度规则容易误报，现在可加一条"CHM 近 0 且极平滑"的强判据
  • 道路：CHM ≈ 0 且亮 → 比单靠亮度可靠得多
10
草地回检 —— 退役（或降级为兜底）
🎉
原来为解决草地问题而做的方案 A（颜色+形态）和 方案 B（株行距网格周期性回检），在 DSM 到位后都不再需要。

建议保留代码但默认关闭（--grass-recheck 改为 opt-in）， 作为"DSM 缺失/质量差"时的兜底。

顺带说：方案 B 里那个尺寸闸门（今天刚修的 bug）也一并退休—— 它本来就是为在没有高度信息时硬凑判据而打的补丁。

五、风险与注意事项

风险影响对策
DSM 与正射错位高度套错地物，全盘失效 开工前必查对齐（第 0 步）
DTM 估算窗口不当高度整体偏移 窗口 30~50 m；用结果直方图验证
密林区 DTM 失真该处高度被低估 园区有空地/道路做控制点，整体可控；局部标注"不确定"
摄影测量 DSM 毛刺假的"高矮边界" 中值滤波 + 形态学清理
幼树 vs 草地的 1.5 m 边界边界附近混淆 需你标定：幼树到底算不算可种植？
DSM 分辨率低于正射高度边界变模糊 重采样到正射网格；注意不要过度插值

六、实施清单

  1. 【你】找出航测工程里的 DSM（`.dsm.tif` / `.tif` 后缀带 dsm / 打开原工程导出） 或点云（`.laz` / `.las`）
  2. 【你】确认当初航测软件（DJI Terra / Pix4D / Metashape）—— 便于我判断 DSM 的生成参数与可靠性
  3. 【我】写 CHM 生成模块 + 对齐检查
  4. 【你】标定三条高度阈值（我给出读值脚本，你只需确认几个已知点）
  5. 【我】改造树冠分割为双证据判据，新增「低矮植被」类别
  6. 【我】全幅重跑 + 对比新旧结果
  7. 【你】目视验收（重点看原来的草地漏检区）

七、如果拿不到 DSM（备用路线）

那就回到"标注 + 训练分类器"，但必须做两处关键改造 （这是另一个 AI 提出的、且我认同的批评）：

改造原因
特征必须局部归一化 跨航带曝光差 3 倍，任何绝对值特征（原始 RGB / ExG / 未归一化的深度特征） 直接喂随机森林，决策树会把分裂阈值绑死在特定航带的亮度上 → 训练集 99%，一换航带就崩。
对策：在 10~12 m（约 1.2~1.5 倍株距）窗口内做局部 Z-score 归一化， 或先做 CLAHE 再提特征。
按树冠尺度池化，而非逐像素 油棕与草地的区别不在单片叶子（局部都是亮绿），而在 8.35 m 尺度上的"放射状树心 + 叶片阴影交替"。
对策：按网格单元 / 超像素聚合后再提特征；若用 DINOv2， 必须在归一化后的图上提取，并在 ~4 m 半径上做特征池化。
算力提醒：本机是 CPU 版 torch（4 核、无独显）。 全幅跑 DINOv2 / SAM2 会慢到难以忍受。若无 GPU， 备用路线应优先用纯 numpy/scipy 的局部归一化特征，分类器用随机森林 / LightGBM。
