# 桌面端使用手册

> 给**最终用户 / 现场作业员**看。不讲原理，只讲怎么点。
> 想知道"为什么这么设计"，看同目录的 `桌面端实现说明.html`。

---

## 0. 这是什么

一个装在 Windows 上的桌面软件：给它一张油棕园的航拍图，它告诉你**哪几块地该补种、补多少棵、每棵种在哪**，
最后给你一沓文件，现场拿着就能干活。

**它不需要你装 Python、不需要装 GIS 软件** —— 安装包里已经带了全部运行时。

---

## 1. 安装

双击 `Forest Gap Detection_x.y.z_x64-setup.exe`，一路下一步。

- 默认装到 `%LOCALAPPDATA%\Forest Gap Detection`（不需要管理员权限）
- 装完从「开始菜单」或桌面快捷方式启动
- 首次启动会在 `%LOCALAPPDATA%\fgd\data` 建一个数据目录

> **卸载**：用安装目录里的 `uninstall.exe` 或「设置 → 应用」。
> ⚠️ **不要手动删安装目录** —— 卸载记录和磁盘对不上，下次装会弹 `Unable to install`。

---

## 2. 第一次打开：选两个文件

首次启动会弹一张卡片，只做两件事：

| 步骤 | 选什么 | 说明 |
|---|---|---|
| ① | **正射影像**（`.tif` / `.tiff`） | 必填。就是那张几 GB 的航拍图 |
| ② | **检测结果**（`.geojson`） | 可选。有历史结果就选，没有就跳过 |

点「开始使用 →」，软件会记住路径，**下次打开直接用**。

> 想换数据：点右上角**「数据」**，会重新弹出这张卡片。

**关于配套文件**：如果你把一整套数据（航拍图 + `chm.tif` + `segment.tif` + `forest-mask*.geojson`）
放在同一个文件夹里，软件会**自动去那儿找**，不用一个个指定。

---

## 3. 干活三步

### ① 圈出要检测的范围（可选，但强烈建议）

两种方式，选一种：

- **手绘**：点「① 圈选 Target Block」→ 在地图上依次点几个顶点 → 双击闭合
- **导入**：点「导入范围」→ 选 `.kml` 或 `.geojson`（奥维、Google Earth 都能导出）

导入后地图会**自动飞到那个位置**，让你确认框住了哪片地。

> **为什么建议圈**：不圈就跑整幅，6 分钟；圈了只跑圈内，**3 分钟**。
> 而且圈外的天然林、邻居家的园子从一开始就被排除，不会再来捣乱。

### ② 开始检测

点「② 开始检测」。

**第一次会先"体检"**（一秒）：

- 全绿 → 直接开跑，不打扰你
- 有问题 → 弹一张卡片，逐项说清"缺什么 / 会有什么后果"
  - 红色 = 必须解决（点「去选择数据」）
  - 黄色 = 会影响结果但能跑（点「仍然开始」自己担着）

跑起来后顶部有一条进度带：

```
检测中 24% ｜ 128 / 528 块 ｜ 已用 1 分 25 秒 ｜ 预计剩余 4 分 24 秒 ｜ 已发现 312 块空地
```

想中止就点右边的「取消」—— 子进程会被杀掉，不会留后台。

跑完变成绿色的「✓ 检测完成 · 1,443 块 · 用时 5 分 50 秒」，结果**自动载入**。

### ③ 估算 + 导出

- **⚡ 估算可种植数量** —— 在地图上标出每个补种点位，并给出双口径株数
- **导出交付包** —— 见第 5 节

## 4. 复核：把算法的错误改掉

这一步决定交付质量。1,726 块里通常有几百块需要人看一眼。

### 4.1 复核清单（右面板「复核」标签）

默认打开就是这个标签，**按面积从大到小排** —— 前 30 个大块通常占 80% 的争议面积。

- 筛选：`全部` / `待复核` / `已改过` / `人工新增`
- 最小面积：`不限` / `≥100` / `≥500` / `≥1000`
- **点任意一行** → 地图飞过去并高亮（如果该类别是隐藏的，会自动帮你打开）

### 4.2 三种改法

| 想做什么 | 怎么做 |
|---|---|
| **改类别**（这块其实是道路） | 选中 → 右侧「属性」里改下拉框 |
| **删除**（这块是误报） | 选中 → 按 `Delete`，或点属性面板的「删除此多边形」 |
| **补画**（算法漏了） | 点「➕ 新增空地」→ 在地图上画 |

### 4.3 批量处理（一片都是误报时）

1. 点「▭ 框选多选」→ 在地图上拖一个方框
2. 底部出现批量栏：`已选 12 块 · 合计 3,420 m² · 连片空地 8 · 不确定 4`
3. 选好目标类别 → 点「应用改判」；或直接点「删除」

> **重要**：框选**只认你左侧勾了勾的类别**。
> 道路、水体这些默认是隐藏的，就算框到了也不会被选中 —— 防止误删看不见的东西。

### 4.4 改错了怎么办

**`Ctrl + Z` 撤回**，`Ctrl + Y` 重做。

- **一次批量操作 = 一次撤回**：框选删 40 块，按一次 `Ctrl+Z` 全部回来
- 最多能撤 40 步
- 拖拐点时，一次拖动只算一步（不会把额度用光）

工具栏左侧的 `↶ 3` `↷ 1` 显示还能撤/重做几步。

### 4.5 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl + Z` | 撤回 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做 |
| `Delete` / `Backspace` | 删除选中（可多选） |
| `Esc` | 退出当前模式 / 取消选择 |
| `Shift` 或 `Ctrl` + 点击 | 加选 / 减选 |

> 光标在输入框里时，这些快捷键**全部让位**给输入框（不会误删多边形）。

## 5. 导出交付包

点「导出交付包」：

1. **选输出目录**（记住上次选择；浏览器里可以直接手填路径）
2. 确认摘要：要素数 / 退让距离 / 人工痕迹 / 范围
3. 点「开始导出」
4. 完成后列出全部文件，点 **「📂 打开文件夹」** 直接去拷走

### 5.1 交付包里有什么（21 个文件）

| 文件 | 给谁用 |
|---|---|
| `gaps-all-wgs84.geojson` | GIS 通用格式 |
| `gaps-all-utm49n.geojson` | 现场量算（单位是米） |
| `gaps-all-wgs84-shp.zip` | **ArcGIS** 拖进去就能出图 |
| `gaps-all-utm49n-shp.zip` | 同上，投影坐标版 |
| `gaps-all.kml` | **奥维 / Google Earth** 打开 |
| `by-class/*.zip`（8 个） | 按类别分开的单层文件 |
| `planting-points-wgs84.geojson` | 补种点位 |
| `planting-points-utm49n.geojson` | 同上，米制 |
| `planting-points-wgs84-shp.zip` | 点位 Shapefile |
| `planting-points-utm49n-shp.zip` | 同上 |
| `planting-points.kml` | 点位 KML（手机导航到每个坑位） |
| `planting-points.csv` | **手持 GPS 放样**（一行一个点） |
| `gaps-edited.csv` | 业务方直接看的表格 |
| `补种勘察一页报告.html` | **给主管签字**，`Ctrl+P` 存 PDF |

> **关键**：这些文件里是**你复核之后**的结果。改判、剔除、补画全都在里面。

### 5.2 一页报告

双击打开 `补种勘察一页报告.html`，浏览器里 `Ctrl + P` 就能打印或存成 PDF。

五块内容：参数卡片 → 三档口径（含图表）→ 要买多少苗 → 你改了多少 → 最大的 20 块。

## 6. 出问题了看哪里

### 6.1 先看日志

```
%LOCALAPPDATA%\fgd\logs\app.log
```

这里会写清楚：用的是打包运行时还是开发环境、数据根在哪、瓦片服务起来没有。
**报问题的时候把最后 20 行贴出来，基本就能定位。**

### 6.2 常见症状

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 地图一片黑，顶部写「影像未连接」 | 没选影像，或服务还没起来 | 点「数据」选影像；已选过就等 10 秒（首次要建索引） |
| 弹「还差一点，检测没法开始」 | 缺关键文件 | 按卡片提示补文件，或点「去选择数据」 |
| 弹「这几项会让结果不准」 | 缺 CHM / 分割 / 森林掩膜 | 看黄色项说的后果，能接受就「仍然开始」 |
| 检测跑完但结果明显偏少 | 大概率缺 CHM（退化成只看颜色） | 看日志里有没有 `W1004` |
| 导入 KML 提示「请先解压」 | 选的是 `.kmz`（压缩包） | 解压出 `.kml` 再导入 |
| 导入提示「这看起来是投影坐标」 | KML 里是 UTM 米，不是经纬度 | 在奥维/GE 里导出成 WGS84 经纬度 |
| 导出后文件夹是空的 | 输出目录没写权限 | 换一个目录（别选 `C:\Program Files`） |
| 装的时候弹 `Unable to install` | 上次是手动删的安装目录 | 用 `uninstall.exe` 卸干净再装 |

### 6.3 性能参考

| 场景 | 耗时（8 核机器） |
|---|---|
| 全量 528 瓦片 | **约 6 分钟** |
| ROI 121 瓦片 | **约 3 分钟** |
| 打开影像（首次建索引） | 10~20 秒 |

> 机器内存建议 **8 GB 以上**。并行进程数可在「⚙ 检测参数」里调：
> 1（串行，最稳）/ 2（低配）/ 4（默认）/ 6（最快）。

---

## 7. 几条要记住的

1. **卸载走 `uninstall.exe`**，别手删目录
2. **圈了范围再检测**，快一倍且更干净
3. **框选前先确认左侧勾了哪些类别** —— 只有勾了的才会被选中
4. **交付前一定过一遍复核清单**，尤其是面积最大的那 20 块
5. 报问题时附上 `app.log` 的最后 20 行
