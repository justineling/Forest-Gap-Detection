分类不是单一的。前 4 块「连片空地」的构成高度一致： 35~39% 黄褐裸土 + 41~47% 暗区（阴影/死株/深色覆盖物）+ 7~26% 亮白（道路）， 几乎没有绿色植被（强绿 0%）。第 5 块却是完全相反的情况：89.7% 强绿，是纯草地。

这说明：被归到同一个 open_patch 类别的 380 块空地，实际上是两种完全不同的地物：

  • 基建型（黄褐 + 阴影 + 白路碎片混合，无植被）：园区内未硬化的作业道、堆料场、已平整待种地
  • 草荒型（强绿为主，草地型光谱）：荒废的草地、林间大片空闲地

两者都「不可种植」在当前语境下需要分开讨论——基建型是规划用地（不该种），草荒型才是真该补种的。 这与用户「道路 / 排水预留带不算要补种的地」的判断方向一致。

五、⚠️ 核心风险：草地会被误判成油棕

用户明确指出「油棕与绿地色彩差距很大」。这个判断成立，但方向出乎意料—— 问题不是「分不开」，而是分错方向。

草地的 ExG 是 136.8，油棕中上部只有 88.6 —— 草地「更绿」54%。
现有算法判据是「ExG 高于阈值 = 树冠」。因此草地会被判成树冠， 随之被从「空地」中扣除，导致真该补种的草地被漏检。

5.2 为什么会这样

纯草皮是单一、鲜嫩、反射均匀的植物叶片，绿度极高； 油棕树冠是多层伞状叶片 + 大量阴影缝隙的立体结构， 在正射影像上被平均后，绿度被内部的暗部拉低。所以「更绿」不等于「更像树」。

六、结论与建议

对用户四条领域的逐条回应

✅
① 道路是白色/偏白的 —— 确认成立。 已定位到完整路网（填充率 1.3% 的线状网络），光谱签名干净（L>170, S<0.18, ExG≈−5）， 可以可靠地自动提取并作为「不可种植」图层扣减。
✅
② 河流/水塘不可种植 —— 成立，但当前占比很小。 水体规则（B≥G>R）在全图命中仅 0.42%（约 9.6 万 m²）。 可在同一套「排除图层」里与道路合并处理。注意：深水可能被归入「暗区」（3.51%）， 建议按「暗 + 低 ExG + 极低纹理」补充识别。
⚠️
③ 油棕 vs 草地 —— 目前不能正确区分，且会误判。 这是本轮最需要修的算法缺陷。三个可选改法（见下）。
✅
④ ArcGIS 查看空地分布 —— 已生成 4 种格式，见第七节。

建议的算法改进（三个方向，推荐组合使用）

  1. 【必做】引入「不可种植图层」前置扣除
    在树冠识别之前，先用颜色规则提取 道路 + 水体 + 硬质场地， 生成一张 mask，把这块区域直接从「候选空地」里剔除。 好处：与现有判据完全解耦，不碰核心算法，风险最低。
    工作量小 立即可做
  2. 【必做】引入纹理特征区分草地 / 树冠
    实测纹理 std 是当前最有区分力的特征。建议加一路「纹理通道」： 大块平滑高绿区（纹理 < 15 且 ExG 高）判为草地/裸地， 破碎高绿区（纹理 > 35 且呈周期性）判为树冠。 可与现有的株行距网格先验结合——草地不服从株行距网格，树冠服从。
    需调参 建议先在小区域验证
  3. 【建议】新增两个地物类别
    CLASS_ROAD（道路/硬化）、CLASS_WATER（水体）， 与「预留带」一起归入「不可种植」。输出 GeoJSON 时单独成层， 这样在 ArcGIS 里可以分开控制符号，也方便用户人工核对。
    纯增量 向后兼容
⚠️ 但请先别急——建议用户先做一件事： 在 ArcGIS 里打开第七节提供的文件，人工抽检 5~10 块最大的「连片空地」， 确认它们实际是什么（作业道？堆料场？荒草地？）。 这直接决定第 1 条建议里的「不可种植图层」应该包含哪些地物，以及要不要新增类别。

7.2 操作步骤（ArcGIS Pro）

  1. 打开 ArcGIS Pro，新建或打开一个工程
  2. 先把 TIF 拖进去——但 3.5 GB 的 BigTIFF 建议先建金字塔（ArcGIS 会提示）， 或者干脆只加影像不显示全图，靠缩放去看细节
  3. 菜单 Map → Add Data → Data，选择 gaps-all.geojson
    如果提示不支持，就把 gaps-all-shp.zip 解压后选 .shp 文件
  4. 右键图层 → Symbology → 按 gclass_cn 字段分类着色： 连片空地=橙、株位空缺=红、林间空隙=黄、不确定=灰
  5. 右键图层 → Labeling，字段选 gap_id 或 area_sqm
  6. 打开属性表（右键 → Open Attribute Table），可按面积排序，从大到小逐块核对

7.3 操作步骤（ArcMap 10.x）

  1. 若版本 ≥10.5：File → Add Data → Add Data，直接选 GeoJSON
  2. 若版本 <10.5：解压 gaps-all-shp.zip，选 gaps-all.shp
  3. 或使用 Conversion Tools → JSON → JSON To Features 手动转换

7.4 只有 Google Earth？

双击 gaps-all.kml 即可。里面已经按类别分好文件夹（可勾选显示/隐藏）， 每块空地点击后能看到面积、长宽比、覆盖率。这是最轻量的核对方式， 适合快速扫一遍大块空地长什么样。

💡 小提示：在 ArcGIS 里核对时，建议把影像透明度和多边形填充透明度都调到 50% 左右， 这样能同时看到底图纹理和多边形边界，便于判断「这块到底是路、是水塘、还是真的空着」。

8.2 ExG × 饱和度 地物分布图

把各地物画在同一张二维图上，直观看出它们的可分离性。灰点是全图 Top20 色族， 彩点是本报告涉及的具体地物样本。红框区域是草地与油棕的混淆带。

读图要点：
  • 连片空地（棕点）位于图的左下角——低绿度 + 低饱和，与其他地物隔着明显的空白带，非常容易分离
  • 白路（灰白点）位于左上角——低绿度 + 极低饱和，同样孤立
  • 草地与油棕挤在右上同一片区域，单靠颜色和饱和度无法分开——这是核心难点
  • 株位空缺落在中间偏上，与油棕接近，但纹理指标能拉开差距（见 5.3 节）
